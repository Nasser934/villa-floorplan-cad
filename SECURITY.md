# Security policy

## Reporting

Do not open a public issue for a security problem or for sensitive building data.

Contact the repository owner privately through GitHub with:

- A clear description.
- Reproduction steps.
- Affected files and versions.
- Expected impact.
- A proposed fix when available.

## Sensitive project data

Residential plans may contain private locations, access paths, room layouts, security features, and household information. Remove or anonymise this data before sharing logs, examples, screenshots, or issue attachments.

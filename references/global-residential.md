# Global residential villa planning guidance

Use this checklist for every project before applying local rules. It is jurisdiction-neutral and uses metric units.

## Design sequence

1. Record the site boundary, street access, north direction, setbacks, easements, levels, climate, and neighbouring conditions.
2. Confirm the household, guest pattern, accessibility needs, staff/service needs, vehicle count, outdoor spaces, and future expansion.
3. Separate public/guest, family/private, service, vertical circulation, and external zones.
4. Establish stairs, elevator, shafts, wet rooms, kitchen, laundry, plant, storage, and waste routes before final room placement.
5. Test room size, furniture fit, door swings, corridor width, natural light, ventilation, privacy, parking, and service access.
6. Apply the current local planning, building, fire, accessibility, energy, sanitation, and utility rules through a jurisdiction profile.

## Global baseline

The packaged `generic-metric` profile is a design baseline, not a building code. It provides editable thresholds for walls, doors, corridors, storage, service routes, kitchen-to-dining distance, plumbing alignment, floor heights, and parapets.

Local requirements always take priority. Record each local source, edition, authority, and project interpretation in `program.json`.
